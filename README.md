# Population-wide variation in connectopic organization of cerebral language hubs

Code accompanying this preprint:

Preprint: https://www.biorxiv.org/content/10.64898/2026.03.12.711274v1

In short, this paper used the following software packages:
- GCTA (https://cnsgenomics.com/software/gcta/#GREML)
- FUMA (https://fuma.ctglab.nl/)
- MAGMA (https://ctg.cncr.nl/software/magma, also implemented in FUMA)
- PRS-CS (https://github.com/getian107/PRScs)
- mediation package (https://imai.fas.harvard.edu/software/mediation.html)
- REGENIE (https://rgcgithub.github.io/regenie/install/)
- Neural Admixture (https://github.com/AI-sandbox/neural-admixture)
- CONGRADS (https://github.com/koenhaak/congrads)
- FSL (https://fsl.fmrib.ox.ac.uk/fsl/docs/)

All software for this paper is publicly available.
